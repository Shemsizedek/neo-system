# NOUS-RUDWAAN-006 — Meta Muse / Business Intelligence Bridge

## Strategy
Use Meta's managed AI infrastructure where it is strongest and keep Nous OS as the canonical control plane.

### Meta plane
Meta AI / Muse / Muse Spark provide:
- Instagram-native business context
- connected-app access
- background agentic tasks
- web research
- multimodal generation
- document generation
- business/ad performance analysis

### Nous plane
Nous OS remains responsible for:
- canonical Noology doctrine
- private and restricted knowledge
- NEOsync orchestration
- approval gates
- provenance
- audit receipts
- privileged action routing
- cross-system integration

## Verified Meta capabilities
Meta's current public product pages state that Meta AI can link an Instagram professional account, Meta Ads Manager, and Google Workspace for business analysis and content/performance work.

Muse supports connected apps, multi-step tasks, background work, and user-reviewed permissions.

Muse Spark powers Meta AI and is being offered via API in private preview to select partners. A generally available public Muse Spark API has not been verified.

## Operating rule
Do not rebuild Meta's commodity agentic infrastructure when Meta already provides it. Use Meta as an execution/compute surface, while Nous OS controls identity, doctrine, authority, and auditability.

## Trust boundary
A response produced natively by the AI Studio character is not considered Nous-verified unless the request has traversed an approved Nous path and carries a receipt or provenance marker.
