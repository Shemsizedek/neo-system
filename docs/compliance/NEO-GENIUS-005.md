## Government eGaaS Bitcoin reserve technical pilot
Next demo is **operator-provided/public BTC addresses ONLY, with explicit source provenance**; never claim an address is a Texas or U.S. reserve without written agency approval.
- Read-only source block-height-consistent BTC balance records.
- Third-party block explorer or independently run node corroboration.
- A custodian statement and discrepancy register; differentiate balance observation vs agency ownership and reserves attestations.
- Reproducible stale source/outage, price fallback, differing source-height and reconciliation discrepancy tests.
- Separate public transparency outputs from encrypted administrator evidence; never expose keys, government PII or confidential records.
- Independent security review, federal/state accessibility and TX-RAMP contract scoping before government use.
