# NEO System Documentation

Welcome to the public technical documentation for **NEO System**, a modular, provenance-first digital control plane developed within the Shelton Estate & Co. ecosystem.

**Source of truth:** [Shemsizedek/neo-system](https://github.com/Shemsizedek/neo-system), branch `main`. This GitBook space is intended to follow the Markdown files under `docs/` through Git Sync.

{% hint style="info" %}
**Release and authority boundary:** Documentation describes a mix of implemented sandbox functionality, prototypes, designs, and proposed integrations. It must not be construed as proof of a live financial service, verified asset ownership, governmental authority, regulatory approval, production settlement, or third-party institutional connectivity. Refer to individual documents and acceptance evidence for each capability.
{% endhint %}
