# Contributing to NEO public documentation

Documentation proposals are welcome through the project's [GitHub repository](https://github.com/Shemsizedek/neo-system).

## Process

1. Propose a focused change to a Markdown file in `docs/gitbook-public/`.
2. Link a public source, code change, test or approved canonical record supporting technical claims.
3. Clearly identify prototype, test, staging and production status.
4. Avoid personal data, private legal matters, credential material and restricted operational instructions.
5. Submit a pull request for review. Do not self-publish material requiring institutional, security, legal or financial approval.

The Git repository is the authoritative history. Any GitBook visual edits should reconcile through the same Git review workflow before public release.

For security-sensitive reports, do not post exploit details or credentials in public issues. The repository's [SECURITY.md](https://github.com/Shemsizedek/neo-system/blob/main/SECURITY.md) is currently a template; an approved private reporting contact and process are required before publication of a complete disclosure policy.
