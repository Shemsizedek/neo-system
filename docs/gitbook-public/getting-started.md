# Getting started

The NEO System connects software prototypes and documentation concerning institutional administration, provenance-centered knowledge work, education, digital commerce, and Bitcoin/Counterparty research.

## Explore the source

1. Read the [repository README](https://github.com/Shemsizedek/neo-system/blob/main/README.md) for scope and release boundaries.
2. Read the [core architecture specification](https://github.com/Shemsizedek/neo-system/blob/main/docs/ARCHITECTURE.md).
3. Review the [NEO Algo overview](https://github.com/Shemsizedek/neo-system/blob/main/docs/NEO_ALGO.md) for the project's source/provenance framework.
4. Use the source files and tests to assess specific implementations; a documentation page alone does not demonstrate an operational integration.

## Developer quickstart (source-based)

The main repository lists the following local workflow:

```bash
npm install
npm run dev
```

A production build is documented as `npm run build`. Consult the repository's current `package.json` and project-specific setup files before deploying.

## What the project does not assert

Repository presence does **not** establish live banking or custodial services, licensed financial activity, government authority, court jurisdiction, production blockchain settlement, or operational security guarantees. Capabilities requiring third parties depend on approved, tested integrations and applicable legal requirements.
