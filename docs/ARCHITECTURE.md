# NEO SYSTEMS — ORIGIN Architecture v0.1

NEO SYSTEMS is the enterprise technology and intelligence control plane for the NEO ecosystem.

## Layers

1. **Intelligence** — NEO PRIME, NEO AI, NEOsync.
2. **Data** — registries, knowledge, analytics, ledgers, observability.
3. **Infrastructure** — NEO CLOUD, NEO CHAIN, NEO SECURITY.
4. **Financial applications** — NEO Exchange, NEO Teller, NEO Counter, NEOpay.
5. **Developer and enterprise services** — APIs, SDKs, workflows, marketplace.

## Truth states

Every major capability should be classified as one of: `fact`, `assumption`, `proposal`, `simulation`, or `deployed`.

## v0.1 objective

The first release provides a machine-readable system definition, a project registry, and a dependency-free CLI so architecture can become executable configuration rather than scattered notes.

## Next engineering milestones

- JSON Schema validation for registries.
- Agent registry with missions, tools, permissions, and human approval rules.
- REST control-plane API.
- Persistent state layer.
- Authentication and RBAC.
- Observability and audit events.
- Bitcoin/Counterparty adapter interfaces.
- Gemini and ChatGPT node synchronization format.
