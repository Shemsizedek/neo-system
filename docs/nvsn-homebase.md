# NVSN Home Base

Canonical public hostname: `nvsn.holytemples.org`

The hostname is the intended public home base for the NEO Virtual Satellite Network (NVSN). Production DNS and hosting activation must be verified independently before the hostname is represented as live.

## Service boundaries

- NVSN is the software-defined communications fabric.
- NEO Wire is an application/service layer operating across NVSN and compatible transports.
- Bitcoin is a settlement rail, not bulk communications bandwidth.
- Counterparty is the Bitcoin-native asset/tokenization layer.
- NEOsync coordinates approved NEO-system workflows.

## v0.3 target
