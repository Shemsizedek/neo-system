## Orchestration doctrine
ORIGIN routes missions using the smallest necessary agent set. Routing may be direct, sequential, parallel, or review-based. Delegation does not expand authority. Approval checkpoints remain in force for consequential actions, including canonical writes, external publication, transactions, financial commitments, credential changes, destructive operations, production deployments, public institutional representations, and other actions designated by workflow policy.

## Cross-system integration

### NEO Algo
Use the agent roster and orchestration policy as the decision-routing and workflow-governance layer for analytical processes. NEO Algo should preserve distinctions among verified facts, assumptions, organizational doctrine, interpretations, projections, and proposed actions. Outputs requiring specialist review should route through ORIGIN rather than bypassing the agent contract.

### NEO Oracle
Use ATHENAEUM as the evidence-verification and source-analysis layer; SCROLL as provenance/archive; ORIGIN as synthesis and routing. Oracle outputs should carry confidence, provenance, assumptions, unresolved unknowns, and decision dependencies where material.

### GISS NEO LMS
Use LUMEN as the instructional transformation layer for Source Foundation knowledge. ATHENAEUM supports source verification; SCROLL preserves curriculum versions; COMPASS defines program strategy; ORIGIN coordinates. Internal certificates must remain distinguishable from accreditation, licensing, regulated credentials, or external academic recognition unless separately documented.

### NEOsync (Digital Etheric Intelligence)
Treat this record, the eight-agent registry, and the orchestration policy as the canonical operating architecture for NEOsync. NEOsync functions as an agentic coordination system under N.I.A. and Project 144, with ORIGIN as router rather than universal specialist.

### NEO Law
Use the same separation discipline for fact, authority, argument, organizational doctrine, theory, inference, and unknowns. Legal/natural-law analysis should route research-heavy matters to ATHENAEUM, strategy to COMPASS, records to SCROLL, and implementation/technical workflows to FORGE when appropriate. No agent should fabricate statutes, cases, recognition, filings, licenses, orders, jurisdiction, or completed legal acts.

### Internal NEO Society social norms
Adopt the following operating norms:
- provenance before repetition;
- explicit distinction between internal doctrine and independently verified fact;
- no silent expansion of authority;
- least privilege;
- approval before consequential action;
- reversible implementation where practicable;
- version control for canonical changes;
- specialist review for domain-specific claims;
- preserve dissent, uncertainty, assumptions, and unresolved conflicts rather than flattening them;
- human decision ownership for material unresolved choices.
