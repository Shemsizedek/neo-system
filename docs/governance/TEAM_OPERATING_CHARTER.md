## ChatGPT workspace protocol
1. Maintain one Project 144 shared project context for governance and NEO Core. Keep separate, clearly titled chats for Architecture, Delivery, Finance/Compliance, and Team Communications.
2. Start each workstream chat with owner, objective, current gate, links to canonical files, and open blockers. Do not rely on chat history alone as the system of record.
3. Record final decisions and milestone outcomes in version-controlled files or an authorized shared tracker. Link the record back in the chat.
4. Use connected GitHub for code, issues, pull requests and technical reviews. Use an approved shared document or task system for non-code work only after access is verified.
5. Before sharing project chats or files, review membership, confidential data, connector permissions, and any external recipients.
6. AI-generated recommendations must be labeled PROPOSED until a human owner approves. No AI-initiated spending, executive appointments, sensitive disclosure, or production deployment without approval.

## Communication cadence (proposed)
- Daily asynchronous update: Done / Next / Blocked / Owner / Evidence link.
- Weekly leadership review: milestones, risk, decisions and dependencies.
- Urgent incident escalation: contact designated Security/Technology Lead outside chat; do not treat ChatGPT as an emergency notification channel.
