# NEOsync OS — ORIGIN

NEOsync OS is the command-and-control layer for the NEO System. ORIGIN is the first foundation release: a modular JARVIS-style architecture centered on NEO Prime, structured memory, specialized agents, permissioned execution, and an auditable command bus.

## Core modules

- **NEO Prime** — central orchestrator
- **NEO Command** — natural-language command bus
- **NEO Memory** — structured institutional memory
- **NEO Agents** — specialized agent registry
- **NEO Senses** — connectors and external data adapters
- **NEO Guard** — authorization, risk classification, and audit
- **NEO Console** — operator dashboard
- **NEO Automations** — scheduled and event-driven workflows

## Operating rule

NEOsync distinguishes planning from execution. Research, analysis, summarization, organization, and drafting may run autonomously. External communications, publishing, high-impact edits, financial actions, legal commitments, destructive operations, and irreversible actions require elevated authorization.

## Initial command flow

`COMMAND -> INTENT -> MEMORY -> AGENTS -> TOOLS -> GUARD -> EXECUTION -> RESULT`

## Status

ORIGIN v1 foundation. Runtime, UI, connectors, persistence, and voice layers follow in subsequent releases.
