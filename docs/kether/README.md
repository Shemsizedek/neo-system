# NEO Kether Tamerean security kernels

This directory contains reference security kernels for the NEO System FOUNDATION / SANDBOX.

Current gate: **v1.3 Delegation-of-Authority Kernel**.

Core rules:

- `AUTHORIZED IDENTITY != AUTHORIZED CAPABILITY`
- `DELEGATED AUTHORITY ⊆ PARENT AUTHORITY`
- `DELEGATION != AUTHORITY CREATION`

The implementation is intentionally fail-closed and does not create real-world governmental, financial, police, military, custody, or other external authority.
