# NEO-GAS v2

NEO-GAS v2 is the defensive intelligence and strategic-resilience subsystem of NEO-System.

## Architecture

- **Backend:** GitHub repository. Versioned operational status is stored under `data/neo-gas/`.
- **Frontend:** GitHub Pages. The Vite application and the dedicated NEO-GAS command page are built from `main` and published by `.github/workflows/github-pages.yml`.
- **Dedicated command page:** `/neo-system/neo-global-arms/`.

## Intelligence model

Assessments should separate:

1. known facts;
2. source references;
3. confidence;
4. analytic judgment;
5. uncertainties;
6. competing hypotheses; and
7. defensive actions.

## V2 upgrades

- Numeric directorate readiness scores and aggregate readiness calculation.
- Expanded maritime and aerospace monitoring domains.
- Assessment schema with severity, confidence, facts, uncertainties, alternatives, source references, and defensive actions.
- GitHub-backed status feed and command alerts.
- GitHub Pages deployment workflow.
- Dedicated responsive command-intelligence frontend.

## Boundary

NEO-GAS does not implement autonomous targeting, attack execution, weapons construction, unlawful weapons acquisition, unauthorized surveillance, or independent governmental police/military authority.
