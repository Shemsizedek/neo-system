# NEO Consumer UI Modernization — Batch 01

This batch establishes the first production-facing cleanup pass across the highest-visibility NEO services.

## Noogle
- Search-first landing experience.
- One search bar on mobile.
- Two search surfaces on desktop.
- Secondary tools and intelligence moved behind progressive disclosure.

## NEO Prime
- Command-first interface.
- Reduced hero and system chrome.
- Advanced intelligence, runtime bridge, and guard information moved into an expandable section.
- Mobile hides non-essential market tape and secondary controls.

## NEOpay
- Compact navigation and smaller control density.
- Mobile prioritizes wallet/payment actions.
- Secondary dashboard cards are reduced on narrow screens.
- Existing non-custodial signing and transaction safety boundaries remain unchanged.

## NEO Exchange
- Sidebar converted into compact horizontal product navigation.
- Market strip is horizontally scrollable instead of occupying fixed grid space.
- Mobile prioritizes chart, order ticket, and order book.
- Portfolio/assets panels are de-emphasized on small screens.

## NEOscan
- Search-first public explorer.
- Compact menu and surface chips replace large persistent navigation.
- Service explanations moved behind an expandable section.
- Mobile prioritizes search and public verification results.

## Consumer standard
The canonical standard remains `docs/consumer-ui-standard.md`.

Follow-on batches should audit NEO Relations, NEO Counter/Teller, GISD, Noogle Finance, NEO Wire, NEO Miner/Generator, and other public or device-facing surfaces for broken links, controls, media, icons, favicons, responsive behavior, copy clarity, and GitHub Pages routing.
