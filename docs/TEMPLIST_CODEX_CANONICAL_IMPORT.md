## Status

## Drafting control

The strict drafting protocol is mandatory:

- Each canon stands on its own.
- Never combine canon numbers.
- Canon numbering is preserved unless the user explicitly changes it.
- Preserve TITLE, CHAPTER, Art., §, and numbered-list structure from supplied source text.
- Default form: `Can. 1671 Text for Canon goes next.`
- Adapt only what is necessary to fit the Branch Temple No. 24 perspective.
- No innovations, added offices, added tribunals, added doctrine, renamed institutions, or extra commentary unless specifically requested.
- When the user supplies an existing canon, the existing canon controls structure and legal function.
