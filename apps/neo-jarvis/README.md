# NEO JARVIS

NEO JARVIS is the operator-facing frontend for NEOsync OS / ORIGIN.

## Public route

`/neo-system/neo-jarvis/`

## Core surfaces

- NEO Command
- NEO Prime status
- NEO Algo 777 → 888 → 999 reasoning cycle
- 999 → 888 → 777 reverse-review model
- NEO Router status
- NEO Guard risk and approval states
- Agent status

## Runtime boundary

The GitHub Pages version is a static interface shell. It does not claim live access to email, calendar, finance, publishing, external APIs, wallets, payments, or other authenticated systems. Live actions must be routed through an authenticated NEO Prime runtime and remain subject to NEO Guard authorization.
