Chromebook Terminal

Run commands on this Chromebook, or connect from it to a remote server over SSH.

1. Start the companion

In your Chromebook Terminal, from the existing neo-system folder, run:

node apps/neo-connect-chromebook/agent.mjs

If it is already running, leave that Terminal tab open. Use the session token it printed. An “address already in use” message usually means another copy is running.

2. Connect this browser

SSH server

First verify the server’s host key and make key-based SSH work in your Chromebook Terminal. This connection uses the Chromebook’s existing SSH configuration and keys. Password prompts are not supported; no key upload is needed. A Google service-account email is not a server address.

Use the companion token, not your Chromebook password. It stays in this page until you disconnect or close it.

Not connected.

Connect runs pwd to check access. If Chrome asks for local-network permission, allow it for this site. Browser pairing with Device A / Device B is separate and is not required here.

3. Run a command

Connect the companion to see command output.

Local commands run as your Chromebook Linux user with an eight-second limit. SSH requests run as the selected server user and wait up to fifteen seconds; remote commands may continue after a timeout or disconnect. Each command starts a new shell, so use cd folder && … when needed. Interactive shells and long-running development servers should stay in the Chromebook Terminal.

Keep the companion on 127.0.0.1; do not forward port 8766 to the internet. Stop it with Ctrl+C to end access. Do not enter passwords or recovery seeds into commands. Connections originate from the Chromebook running the companion; this page does not give this chat remote terminal access.
