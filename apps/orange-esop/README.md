# Orange ESOP Application v0.2

Chaplaincy employee-ownership and Holy Stewardship application layer.

## Scope
- participant registry
- stewardship journal
- vesting/reconciliation views
- certificate/statement generation hooks
- adapters for NEO Books, NEOpay, NEO Explorer and Orange Chip Registry

## Status
Development application. No live ESOP benefits or NEOTRUST transfers are created by this app alone.

## Run
```bash
npm run orange-esop:server
```

Default port: 8799
