# NEO People Search

NEO People Search is the authorized identity-discovery and relationship-intelligence layer for the NEO System.

## Purpose

It answers four operational questions:

1. Who is this person?
2. Are they already represented in an authorized NEO data source?
3. What verified public or consented identifiers connect to them?
4. Are there account-access or security events associated with that identity that require review?

## Allowed data sources

- NEO membership, CRM, LMS, organization, contributor, and account directories where collection is authorized.
- Public professional or organizational profiles and public records that can lawfully be indexed.
- User-submitted profiles and verified identity claims.
- Security/audit telemetry generated by NEO-controlled systems, limited to identity and access metadata needed for defensive monitoring.
- Provenance metadata describing where a result came from and when it was last verified.

## Prohibited behavior

NEO People Search must not be used for covert GPS/location tracking, hidden device surveillance, raw keystroke collection, password collection, private-message harvesting, impersonation, stalking, doxxing, or unauthorized acquisition of non-public personal data.

The system must never label a person as a threat merely because they are outside the NEO ecosystem. Security findings require observable evidence from authorized telemetry and must preserve uncertainty.

## Architecture

```text
NEO Crawler / authorized connectors
              |
              v
      Source Normalization
              |
              v
     NEO People Search API
       |       |        |
       |       |        +--> Provenance / confidence
       |       +-----------> NEO Law policy gate
       +-------------------> NEOsync / NEO Router
                                |
                                +--> NEO Guardian / NEO Hacker
                                     (security events only)
```

## Search modes

- `internal`: authorized NEO directories only.
- `public`: public-source identity discovery.
- `combined`: internal + public results with source separation.
- `security`: identity-linked access events from NEO-controlled systems only.

## Core result model

```json
{
  "person_id": "neo-person:...",
  "display_name": "Example Person",
  "aliases": [],
  "relationship": "member|staff|contributor|external|unknown",
  "identifiers": [],
  "sources": [],
  "confidence": 0.0,
  "security": {
    "status": "no-evidence|review|verified-event",
    "event_refs": []
  }
}
```

## v0.1

This initial implementation provides:

- a policy-aware HTTP API;
- an in-memory adapter for internal/public records;
- provenance-aware search responses;
- security-event correlation that only accepts authorized NEO-system telemetry;
- explicit rejection of prohibited surveillance query intents;
- a minimal browser UI.

Future adapters should plug into NEO Crawler, NEO LMS, NEO Society membership, GitHub/contributor records, and other explicitly authorized sources.
