# NEO SYSTEMS — ORIGIN

NEO SYSTEMS is the enterprise technology, intelligence, data, cloud, blockchain, security, developer, and financial-infrastructure control plane for the NEO ecosystem.

**Codename:** ORIGIN  
**Version:** 0.1.0  
**Status:** Foundation

## Run

Requires Node.js 20+ and no third-party dependencies.

```bash
npm run status
npm start
node apps/origin-cli/index.js projects
node apps/origin-cli/index.js project neopay
npm test
```

## Repository structure

```text
apps/origin-cli/      ORIGIN command interface
config/               Machine-readable system and project registries
docs/                 Architecture documentation
gem/                   Gemini Gem node instruction
packages/core/         Core system loader
packages/registry/     Project registry API
test/                  Built-in Node test suite
```
