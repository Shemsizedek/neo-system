# Shelton Estate & Co. — NEO Estates Prototype Floor-Plan Package

Status: Canonical schematic planning package
Module: NEO-HOUSES-001
Version: 1.0

## Purpose
This package converts the NEO Estates Architectural Design Catalog into schematic prototype layouts. These are concept-level planning diagrams for programming, feasibility, acquisition screening, and architect/developer briefing. They are not permit drawings, construction documents, stamped architectural plans, or engineering documents.

## Universal Adjacency Rules
1. Arrival should connect directly to fellowship/public zones without exposing private residential rooms.
2. Learning/creator zones should be near fellowship space but acoustically separated from bedrooms.
3. Neotherapy/Reflection zones should sit in the quiet side of the plan with visual or physical access to landscape where possible.
4. Service/utility areas should buffer occupied zones from mining/compute.
5. Mining/compute should be detached, exterior-accessed, or placed at the farthest service edge with independent heat/noise control.
6. Private bedrooms should never require passage through creator, public, or mining zones.
7. Landscape should connect to fellowship and Neotherapy zones first.
8. A clear egress and life-safety path governs all layouts.

## Prototype D — NEO Estate Compound
Target: multi-building flagship site

### Site Components
1. Main House — fellowship, dining, family/leadership residence
2. Apprentice / Creator Cottage — resident cohort
3. Creator Studio Building — production, podcasting, editing
4. Neotherapy Pavilion — reflection, teaching, wellness programming
5. Enterprise / Administration Building — business, finance, project management
6. Guest Lodge
7. Healing Garden / Courtyard Spine
8. Utility / Energy / Mining Building
9. Parking / service court kept away from the ceremonial arrival axis

### Site Adjacency
Ceremonial Entry -> Main House -> Central Courtyard
Central Courtyard -> Neotherapy Pavilion
Central Courtyard -> Creator Studio
Central Courtyard -> Apprentice Cottage
Main House -> Guest Lodge
Enterprise Building -> public/visitor access
Utility/Mining Building -> rear service drive only
Garden spine links occupied buildings without crossing industrial/service circulation

### Planning Principle
Human, ceremonial, educational, and creator movement occurs around the central garden. Industrial and mining operations run on a separate service edge.

## Schematic Area Allocation Guidelines

### Compact House
- Residential: 45–55%
- Fellowship/Kitchen: 20–25%
- Learning/Creator: 10–15%
- Neotherapy/Reflection: 8–12%
- Service: 8–12%
- Mining: detached/excluded from gross occupied area where possible

### Creator House
- Residential: 35–45%
- Fellowship: 15–20%
- Creator/Enterprise: 20–25%
- Neotherapy/Reflection: 8–12%
- Service: 8–12%
- Compute: separate plant

### Scholar / Neotherapy
- Residential: 25–35%
- Library/Classroom: 20–30%
- Neotherapy/Reflection: 20–25%
- Fellowship: 10–15%
- Creator: 5–10%
- Service: 8–12%

## Design Review Checklist
Each schematic must confirm:
- code-compliant egress concept;
- accessibility strategy;
- fire separation concept;
- acoustic hierarchy;
- private/public circulation separation;
- Neotherapy privacy;
- creator production isolation;
- clean-air strategy;
- mining heat/noise separation;
- service access;
- garden adjacency;
- expandability;
- budget fit.

## Phase Progression
Schematic Prototype -> Site Fit Test -> Acquisition / Feasibility Underwriting -> Licensed Architect / Engineer -> Code Review -> Cost Estimate -> Construction Documents -> Permitting -> Buildout.

## Canonical Rule
The floor plan must make the philosophy visible:
**human-centered spaces occupy the heart of the property; service and compute infrastructure support the property from the edge.**
