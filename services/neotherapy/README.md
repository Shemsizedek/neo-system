# Neotherapy™ v1.0

Initial additive implementation of the Neotherapy / Nous Field Therapy specification.

## Boundaries
Neotherapy certification is an internal educational/professional credential and is not a state healthcare license. NFM-001 is currently an experimental Noological sensory practice; this module establishes no clinical efficacy claim.

## Core invariants
- Proposition classes: FACT, PERCEPTION, HYPOTHESIS, UNKNOWN.
- Evidence states: D0, H1, O2, P3, R4, V5.
- Active consent and practitioner modality authorization are required before a modality session.
- Evidence promotion requires review; doctrine and hypotheses never silently become validated findings.
- Participant data is separated from general NEO Society / intelligence data.
