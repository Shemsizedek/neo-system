NEO Guardian Privacy Policy

Effective August 28, 2026.

Local-first operation

NEO Guardian performs device-security posture checks locally. Scan history and incident findings are intended to remain on the device. Guardian does not include advertising analytics or background telemetry in this release.

Live features

When you explicitly run a live function, Guardian may make HTTPS requests to the configured service. Public-IP lookup contacts ipify and necessarily exposes the requesting public IP to that service as part of normal Internet routing. Update checks contact the public NEO Guardian version endpoint hosted on GitHub Pages.

Permissions

Guardian requests Internet and network-state access for opt-in live functions, package visibility for installed-app security review, and Android device-authentication capabilities for the protected console. It does not request microphone, camera, contacts, SMS, or precise-location permission.

No attribution claims

Security flags are indicators for review and are not proof that an application, person, organization, or government actor compromised a device.

Support

Issues can be reported through the neo-system issue tracker.
