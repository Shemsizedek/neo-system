# Noology Module

This module is the canonical software foundation for NEOsync Noology inside `neo-system`.

## Included
- `runes.ts` — 25-card Nuwaubic Rune Oracle reference data and 1/3/5 rune casting logic.
- Gemini Gem operating instructions — `docs/gems/noology-gem.md`.

## Design Rules
- User-supplied doctrine is canonical unless explicitly amended.
- Reversed readings are semantic opposites of upright readings unless the rune is marked non-reversible.
- Dafu reads Power in either orientation.
- Hayuh has no reverse.
- The Blank Stone has no reverse.
- Oracle output is interpretive/spiritual guidance, not guaranteed prediction or professional medical/legal/financial advice.
